📌 TCS NQT — Array 5 Questions Short Notes
1. Smallest Element

Pattern: min

int min = arr[0];

for (int i = 1; i < n; i++) {
    if (arr[i] < min) {
        min = arr[i];
    }
}

System.out.println(min);

🧠 Yaad: current < min → update min

Time: O(N) | Space: O(1)

2. Largest Element

Pattern: max

int max = arr[0];

for (int i = 1; i < n; i++) {
    if (arr[i] > max) {
        max = arr[i];
    }
}

System.out.println(max);

🧠 Yaad: current > max → update max

Time: O(N) | Space: O(1)

3. Second Smallest + Second Largest

Pattern:

int smallest = Integer.MAX_VALUE;
int secondSmallest = Integer.MAX_VALUE;

int largest = Integer.MIN_VALUE;
int secondLargest = Integer.MIN_VALUE;

Smallest:

if (arr[i] < smallest) {
    secondSmallest = smallest;
    smallest = arr[i];
}
else if (arr[i] < secondSmallest && arr[i] != smallest) {
    secondSmallest = arr[i];
}

Largest:

if (arr[i] > largest) {
    secondLargest = largest;
    largest = arr[i];
}
else if (arr[i] > secondLargest && arr[i] != largest) {
    secondLargest = arr[i];
}

🧠 Yaad:

New smallest → old smallest becomes second
New largest  → old largest becomes second

Time: O(N) | Space: O(1)

4. Reverse Array

Pattern: Two pointers

int left = 0;
int right = n - 1;

while (left < right) {

    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;

    left++;
    right--;
}

🧠 Yaad:

left →→
←← right
swap → move both

Time: O(N) | Space: O(1)

5. Frequency of Each Element ⭐

Pattern: HashMap

HashMap<Integer, Integer> map = new HashMap<>();

for (int i = 0; i < n; i++) {
    map.put(arr[i], map.getOrDefault(arr[i], 0) + 1);
}

Print:

for (Map.Entry<Integer, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " -> " + entry.getValue());
}

🧠 Yaad:

get → +1 → put

और:

getKey()   → element
getValue() → frequency

Time: O(N) average | Space: O(N)

🔥 5 Questions ka Master Pattern

Reverse        → left + right + swap
